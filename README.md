## Utilisation

**Ouvrir en local**
Double-cliquez sur le fichier `.html`, ou ouvrez-le dans un navigateur.

**Publier en ligne (GitHub Pages)**
1. Onglet **Settings → Pages**
2. Source : branche principale, dossier `/ (root)`
3. Une fois activé, le lecteur est accessible à :
   ```
   https://beauville.github.io/clip-ali-digiy/DIGIYLYFE_ALY_KANE_LECTEUR_PHOTOS.html
   ```
   *(adresse valable une fois GitHub Pages activé)*

> ⚠️ Après chaque envoi de fichier, passez par **Add file → Upload files** et vérifiez que le fichier pèse un vrai poids. Un fichier monté « vide » (quelques octets) ne s'ouvrira pas.

> 🔊 La voix dépend du navigateur et de l'appareil du visiteur. Sur un appareil sans voix française installée, le texte reste lisible à l'écran.
